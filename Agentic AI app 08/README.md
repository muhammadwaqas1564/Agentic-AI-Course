# 🔬 ResearchFlow Lite - Multi-Agent AI Research Assistant

A production-ready multi-agent AI system that orchestrates specialized agents to conduct automated research, summarization, and quality review using local LLMs.

## 🎯 Features

- **Multi-Agent Architecture**: Supervisor agent coordinates specialized agents
- **Free APIs**: Uses arXiv and Wikipedia for research data
- **Local LLMs**: Powered by Ollama (Mistral, Llama2, Llama3)
- **Agent Workflow**: Clear orchestration with logging and visualization
- **Production Ready**: Error handling, logging, environment configuration
- **Clean UI**: Minimal but functional web interface
